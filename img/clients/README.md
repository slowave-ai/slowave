# Client brand marks

These locally bundled marks identify supported third-party clients in the Slowave website. Their owners retain all rights; display identifies compatibility and does not imply affiliation, sponsorship, or endorsement.

| File | Client shown | First-party source |
| --- | --- | --- |
| `claude.svg` | Claude Code and Claude Desktop | [Claude brand site](https://claude.com/favicon.svg) |
| `openai.svg` | Codex (OpenAI parent mark; no distinct Codex mark was located in the brand kit) | [OpenAI Cookbook official repository](https://github.com/openai/openai-cookbook/blob/main/examples/agents_sdk/deployment_manager/frontend/src/openai-logomark.svg) |
| `copilot.svg` | GitHub Copilot CLI (GitHub parent mark; GitHub's current toolkit deprecates the former standalone Copilot logo) | [GitHub favicon](https://github.githubassets.com/favicons/favicon.svg), [Copilot brand guidance](https://brand.github.com/brand-identity/copilot) |
| `cursor.svg` | Cursor | [Cursor brand site](https://cursor.com/brand) |
| `opencode.png` | OpenCode | [OpenCode brand site](https://opencode.ai/brand) |
| `windsurf.svg` | Windsurf | [Windsurf brand site](https://windsurf.com/brand) |
| `antigravity.svg` | Antigravity (simplified arch mark drawn for Slowave; replace with the official mark if Google publishes one) | [Antigravity](https://antigravity.google) |
| `cline.svg` | Cline | [Cline brand site](https://cline.bot/brand) |

The `copilot-dark.svg`, `openai-dark.svg`, and `cline-dark.svg` variants use a light fill for contrast on dark backgrounds. The README selects them with `prefers-color-scheme`, keeping the original marks for light mode.

`opencode-mark.svg` embeds the original OpenCode PNG with a cropped viewBox to remove its outer padding for the README client grid.
